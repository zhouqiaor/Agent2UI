## 1. IdeaHub 现有交互概览

### 1.1 核心功能模块

基于 `ideahub-product-support` 知识体系，IdeaHub 现有交互分为 9 大领域：

| 领域 | 现有交互 | 核心场景 |
|------|----------|----------|
| 🎨 白板书写 | 多人书写、智能书写、笔迹导出 | 课堂教学、会议协作 |
| 📺 无线投屏 | AirPlay/Miracast、扩展/复制模式 | 手机/电脑投屏、多屏互动 |
| 🎤 会议功能 | 视频会议、麦克风、摄像头 | 远程会议、多方协作 |
| ⚙️ 系统设置 | 网络、账号、升级、恢复出厂 | 设备配置、运维管理 |
| 📈 固件升级 | OTA 升级、版本回退 | 设备维护 |
| 🩺 故障排查 | 触控失灵、黑屏、回声 | 问题诊断 |
| 🏢 部署安装 | 会议室装修、布线 | 首次部署 |
| 🔑 激活账号 | 激活码、WeLink 接入 | 账号管理 |
| 📋 快速入门 | 首次开机、初始配置 | 新手指引 |

### 1.2 现有交互模式分析

| 维度 | 现状 | 痛点 |
|------|------|------|
| 输入方式 | 触控 + 物理按键 | 复杂操作需要多次点击 |
| 视觉风格 | HarmonyOS Design | ✅ 符合鸿蒙规范 |
| 反馈机制 | Toast、Dialog、状态指示灯 | 反馈粒度粗，缺少过程反馈 |
| 协作方式 | 多人书写、多设备投屏 | 缺少智能辅助 |
| 智能化程度 | 智能书写（基础） | 缺少 Agent 级智能 |

## 2. A2UI 融合机会分析

### 2.1 融合矩阵

| IdeaHub 模块 | A2UI 增强点 | 交互形式 | 融合价值 | 优先级 |
|-------------|------------|----------|----------|--------|
| **白板书写** | Agent 图形识别与美化 | 语音→图形、手写→规范图形 | 降低书写门槛 50% | P0 |
| **白板书写** | Agent 语音转文字 | 麦克风→文字标注 | 提升记录效率 3x | P0 |
| **会议功能** | Agent 实时字幕 | 语音→屏幕字幕 | 提升会议参与度 | P0 |
| **会议功能** | Agent 会议纪要 | 语音→结构化纪要 | 自动化记录 | P0 |
| **无线投屏** | Agent 内容推荐 | 场景→内容卡片 | 丰富投屏体验 | P1 |
| **系统设置** | Agent 语音配置 | 自然语言→配置项 | 降低配置门槛 | P1 |
| **故障排查** | Agent 智能诊断 | 现象→排查步骤 | 缩短排查时间 60% | P2 |

### 2.2 场景详细设计

#### 场景 1: 白板 + A2UI 增强

```

│  ┌─────────────────────────────────────────┐    │

│  │                                         │    │
│  │                                         │    │
│  └─────────────────────────────────────────┘    │
│                                                  │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐      │
│  │ 🖊 书写  │  │ 📷 拍照  │  │ 🤖 A2UI  │ ← 新增│
│  └──────────┘  └──────────┘  └──────────┘      │

                    │

                    ▼
┌─────────────────────────────────────────────────┐

│  ┌─────────────────────────────────────────┐    │
│  │  🤖 Agent: "已识别三角形，是否美化？"     │    │
│  │                                         │    │
│  │  ┌─────┐  ┌─────┐  ┌─────┐              │    │
│  │  │ ☐ 正 │  │ ☐ 等 │  │ ☐ 直 │ ← 选项   │    │
│  │  └─────┘  └─────┘  └─────┘              │    │
│  │                                         │    │
│  │  [应用美化]  [语音输入]  [关闭]          │    │
│  └─────────────────────────────────────────┘    │
└─────────────────────────────────────────────────┘
```

**交互时序**:
1. 用户点击 🤖 A2UI 按钮 → Agent 进入 Listening 态
2. 用户选择语音或点击 → Agent 进入 Processing 态
3. Agent 识别当前笔迹 → Agent 进入 Done 态，展示结果卡片
4. 用户确认 → 应用美化效果

**设计要点**:
- A2UI 面板使用玻璃拟态（沉浸光感），不遮挡白板主操作区
- Agent 三态动画符合 HarmonyOS 动效规范
- 选项卡片使用品牌浅底色（brand_surface: #E8F3FF）

## 3. 视觉规范对齐

### 3.1 Design Token 映射

A2UI 组件必须严格使用以下令牌：

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--brand` | `#007DFF` | Agent 主按钮、选中态 |
| `--brand-surface` | `#E8F3FF` | Agent 面板背景 |
| `--text-1` | `#181818` | 主文字 |
| `--text-2` | `#666666` | 次级文字 |
| `--text-3` | `#999999` | 辅助文字 |
| `--surface` | `#FFFFFF` | 面板背景 |
| `--surface-muted` | `#F5F6F7` | 输入框底 |
| `--divider` | `#E8EAED` | 分隔线 |
| `--glass` | `rgba(255,255,255,0.72)` | 玻璃拟态 |
| `--r-sm` | `8px` | 小元素圆角 |
| `--r-md` | `12px` | 卡片圆角 |
| `--r-lg` | `16px` | 大面板圆角 |
| `--r-full` | `999px` | 胶囊按钮 |
| `--shadow-card` | `0 2px 8px rgba(0,0,0,0.06)` | 卡片阴影 |
| `--shadow-elev` | `0 6px 16px rgba(0,0,0,0.10)` | 浮层阴影 |

### 3.2 A2UI 特有组件状态

| 组件 | 状态 | 视觉表现 |
|------|------|----------|
| Agent 图标 | idle | 灰色背景 + 默认图标 |
| Agent 图标 | listening | 品牌色 + 声波动画 |
| Agent 图标 | processing | 警告色 + 进度条 |
| Agent 图标 | done | 成功色 + 完成标记 |
| A2UI 面板 | closed | 隐藏 |
| A2UI 面板 | open | 玻璃拟态 + 淡入动画 |
