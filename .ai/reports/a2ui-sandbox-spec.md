## 1. 产品定位

### 1.1 产品愿景

A2UI 体验沙盒是一个**临时轻量级 Web 交互原型**，用于让产品经理、设计师和干系人快速体验 Agent-to-UI 交互模式，收集第一手反馈。

### 1.2 核心目标

| 目标 | 衡量指标 | 优先级 |
|------|----------|--------|
| 体验 A2UI 核心交互 | 支持 5+ 场景切换、Agent 三态交互 | P0 |
| 收集众筹反馈 | 支持反馈收集表单、体验记录导出 | P0 |
| 验证 HarmonyOS Design 规范 | 所有 UI 元素符合 design-tokens | P0 |
| 探索 IdeaHub 融合方案 | 在现有交互中演示 A2UI 增强效果 | P1 |

### 1.3 非目标

- ❌ 不作为生产环境使用
- ❌ 不包含真实 Agent 后端（使用模拟数据）
- ❌ 不覆盖 IdeaHub 全部功能

### 3.2 User Stories

#### F1: 多场景切换体验

```
As a 产品评审员,
I want 在不同 A2UI 场景间快速切换,
So that 我能评估 A2UI 在不同业务场景下的适用性.
```

**验收标准**:
- 支持至少 6 个场景：签到计数、投票表决、课堂答题、分组计分、IdeaHub 白板增强、IdeaHub 会议增强
- 场景切换流畅（< 300ms），有淡入动画
- 场景指示器清晰展示当前场景

#### F2: Agent 三态交互

```
As a 交互设计师,
I want 看到 Agent 的 Listening/Processing/Done 三态反馈,
So that 我能评估 Agent 交互的信息传递效率.
```

**验收标准**:
- Listening 态：显示声波动画 + 监听文字
- Processing 态：显示进度条 + 执行中文字
- Done 态：显示完成标记 + 执行结果
- 状态切换有过渡动画（100-250ms）

#### F3: 反馈收集表单

```
As a 产品经理,
I want 收集体验者对每个场景的反馈,
So that 我能基于真实反馈调整 A2UI 设计方向.
```

**验收标准**:
- 每个场景有独立的反馈入口
- 反馈字段：总体评分（1-5）、交互流畅度（1-5）、Agent 交互自然度（1-5）、文字反馈
- 反馈以 localStorage 形式保存，可导出为 JSON

#### F4: HarmonyOS Design 规范对齐

```
As a 设计师,
I want 所有 UI 元素严格遵循 HarmonyOS Design Token,
So that 我能确认 A2UI 界面符合鸿蒙生态设计标准.
```

**验收标准**:
- 色彩：100% 使用 design-tokens 中的令牌
- 字体：字号取自标准阶梯（Display/Title/Body/Caption）
- 间距：4vp 基数（4/8/12/16/24/32vp）
- 圆角：sm:8 / md:12 / lg:16 / full:胶囊
- 阴影：柔和 20% 透明度黑，多层叠加
- 动效：点击 100ms、列表 250ms、转场 300ms

#### F5: IdeaHub 融合演示

```
As a IdeaHub 产品经理,
I want 看到 A2UI 如何增强 IdeaHub 现有交互,
So that 我能评估 A2UI 在 IdeaHub 产品中的落地场景.
```

**验收标准**:
- 演示 IdeaHub 白板 + A2UI：Agent 辅助书写、智能图形识别
- 演示 IdeaHub 会议 + A2UI：Agent 实时字幕、会议纪要生成
- 演示 IdeaHub 投屏 + A2UI：Agent 内容推荐、多屏协同
- 每个演示包含：原始界面 → A2UI 增强 → 对比说明

## 4. 场景列表与描述

### 4.1 核心 A2UI 场景（P0）

| 场景 | 描述 | 核心交互 |
|------|------|----------|
| 签到计数 | 教育/会议场景：基于名单的快速考勤与签到 | 名单导入、点击签到、语音点名、扫码签到、Agent 播报统计 |

**签到计数子功能清单**：

| 功能模块 | 功能描述 | 优先级 |
|---------|---------|--------|
| 名单管理 | 手动添加、批量导入、示例数据、清空重置 | P0 |
| 触控签到 | 点击姓名切换状态、一键全员签到 | P0 |
| 扫码签到 | 大屏展示二维码、参会者手机扫码签到 | P1 |
| 扫码墙效果 | 签到人员头像/姓名汇聚显示（马赛克效果） | P1 |
| Agent 辅助 | 语音点名、状态播报、未到提醒 | P1 |
| 数据统计 | 应到/已到/未到统计、实时更新 | P0 |
| 投票表决 | 会议场景：快速会议表决 | 触控投票、实时计票、Agent 宣布结果 |
| 课堂答题 | 教育场景：课堂互动答题 | 触控选择、计时、Agent 解析答案 |
| 分组计分 | 教育/会议：团队竞技计分 | 加减分操作、排名展示、Agent 奖励建议 |

### 4.2 IdeaHub 融合场景（P1）

| 场景 | 现有交互 | A2UI 增强 | 融合价值 |
|------|----------|-----------|----------|
| 白板增强 | 手写笔迹、图形绘制 | Agent 智能识别图形、自动美化、语音转文字 | 降低书写门槛，提升效率 |
| 会议增强 | 视频会议、麦克风 | Agent 实时字幕、会议纪要、重点标记 | 提升会议参与度，自动化记录 |
| 投屏增强 | 无线投屏、多屏互动 | Agent 内容推荐、多屏协同布局、跨屏操作 | 提升投屏体验，丰富协作方式 |
| 设置增强 | 系统设置、配置 | Agent 语音配置、自然语言设置 | 降低配置门槛 |

### 4.3 反馈收集入口

每个场景右下角提供 💬 反馈按钮，点击弹出反馈面板。

## 5. 非功能需求

| 维度 | 要求 |
|------|------|

| 设计规范 | 100% 遵循 HarmonyOS Design Tokens v1.2.0 |
