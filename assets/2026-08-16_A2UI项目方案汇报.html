项目定位与目标

一句话定位

一款基于 A2UI（Agent-to-User Interface） 声明式协议的智能协作 APP，让 AI 在教育（智能助教）与会议（智能助理）两个场景中动态生成富交互界面（练习、测验、纪要、待办、数据看板），而非传统聊天框问答。

🧩 UI 由 Agent 生成
所有交互界面由 LLM 按场景动态生成 A2UI JSON，客户端原生渲染，不预置固定页面。
📱 三端覆盖
Web + iOS + Android + HarmonyOS 多端一致体验（共用同一 Catalog）。
⚡ 低自研率
渲染/协议/Agent 大部分复用开源，自研仅聚焦场景编排与业务集成。
🔒 安全可控
组件白名单（Catalog 约束）+ 端侧逻辑，不执行任意代码。

为什么是 A2UI + AGenUI

AGenUI（高德×阿里千问，Apache 2.0，v1.3.1）完整实现 A2UI v0.9：共享 C++ 核心引擎 + iOS/Android/HarmonyOS 三端原生渲染器（渲染零自研）；自带 agenui_catalog.json（25 组件+14 函数）与生成 Skill；配套 AGenUI Studio（BYOK）可做快速验证；支持 npx skills add 一键集成 55+ Agent 运行时。Web 端走 CopilotKit（AG-UI 创建者，支持 React/Angular/Vue/RN）。

IdeaHub 大屏场景落地

为什么 IdeaHub 是理想硬件承载端

IdeaHub（华为企业协作大屏，ES/S/B/K·Board 系列）原生 HarmonyOS、全栈 AI、智慧白板、鸿蒙分布式协同。AGenUI 已支持 HarmonyOS，APP 可经鸿蒙应用生态在大屏原生运行——A2UI 负责"生成什么界面"，IdeaHub 负责"大屏怎么渲染、怎么交互"。

A2UI 能力诉求IdeaHub 承接能力
动态生成富交互界面全栈 AI + 大模型（盘古等可化身 AI 助教/助手）
多模态交互低延迟智慧白板、语音、遥控精灵、触控/手写笔
富交互可视化4K 柔光大屏、信息窗 / 业务驾驶舱
跨设备协同鸿蒙分布式（手机/平板/大屏一拉即合）
组件化安全渲染OPS/鸿蒙应用生态，本地渲染 + 弱网可用

分析华为 IdeaHub 25.0《用户界面使用手册》《常见问题》等官方文档，确认落地 A2UI 的官方技术通道与真实 AI 能力：

文档实证对 A2UI 方案的支撑

关键场景界面原型（框架壳 + A2UI 内容区）

原型已完全重制：不再用孤立的"对话气泡 + 组件卡"，而是呈现完整 App 框架——原生壳（状态栏 / 顶栏 / 底部标签栏，由 App 稳定提供）包裹 A2UI 动态内容区（Agent 按场景实时生成，紫色虚线框标注）。壳不变、内容万变，这正是 A2UI 相比"整页生成 HTML"的安全与一致性优势。

范式说明
■ 原生框架壳：稳定、不随会话变化（导航 / 标签栏 / 页面 chrome） ▦ A2UI 生成内容区：Agent 动态生成，可流式 / 增量更新

用户进入 App 看到熟悉的原生框架；真正"因场景而异"的内容——随堂测验、会议纪要看板、大屏驾驶舱——由 A2UI 协议从 Agent 下发 JSON 蓝图、由端侧原生渲染器（AGenUI / HarmonyOS）绘制，并复用第五章鸿蒙 design tokens。

结论

本设计以 A2UI 为 UI 范式、AGenUI 为三端渲染基石、CopilotKit/AG-UI 为 Web 通道、MeetingMind/Meetily/Whisper 为会议能力、Llama Tutor/LangChain 为教育能力、harmony-design-skill 为统一设计系统，将自研聚焦在"场景编排 + 业务集成 + 领域 Catalog 扩展"上，整体 60%+ 代码来自成熟开源，可快速从 P0 Demo 演进到多端全场景 APP，且天然契合华为 IdeaHub 大屏等硬件承载（AGenUI 已支持 HarmonyOS，IdeaHub 可经鸿蒙应用生态接入；其官方文档进一步印证第三方应用通道与白板智能搜索等 AI 能力，投屏可由 IdeaShare SDK 直接复用，大屏现场助手可由产品知识 Skill 承载）。
